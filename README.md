# Employee Attendance Record in C

## Project Description

A simple C program that uses a structure to store employee attendance details and calculate the attendance percentage.

## Features

- Enter employee details
- Store working days
- Store days present
- Calculate attendance percentage
- Display attendance details

## Technologies Used

- C
- Structures
- Arithmetic Operations
- Conditional Statements

## How to Run

Compile and run the `employee_attendance.c` file using a C compiler.
